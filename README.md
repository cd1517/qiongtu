# 穷图

自用的 iOS 修图 App（SwiftUI + Core Image + Vision），iOS 17+。

- 编辑：裁剪、调色、滤镜（含拍立得）、文字贴纸、涂鸦标记、马赛克、边框背景、图层、拼图
- 美颜 / 美妆 / 皮肤 / 面部重塑 / 美体 / 美发
- AI 修图：修复、光线、消除、构图、大师、相机质感（用自己的 API Key，支持 OpenAI、Gemini、MiniMax、Grok、通义千问、豆包 Seedream、FLUX、OpenAI 兼容接口）
- 封神（杂志封面 / 电影海报）、摄影棚、漫画人生、RAW 冲洗、历史图库

用 Xcode 打开 `XiuTu.xcodeproj`，scheme `XiuTu`。
