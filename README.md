## 功能

- 编辑：裁剪、调色、滤镜（含拍立得）、文字贴纸、涂鸦标记、马赛克、边框背景、图层、拼图
- 美颜 / 美妆 / 皮肤 / 面部重塑 / 美体 / 美发
- AI 修图：修复、光线、消除、构图、大师、相机质感
- 封神（杂志封面 / 电影海报）、摄影棚、漫画人生、RAW 冲洗、历史图库

## 编译

用 Xcode 打开 `XiuTu.xcodeproj`，scheme `XiuTu`，换成你自己的开发者团队后编译。

Release 里的 IPA 用作者的个人开发证书签名，只能装在作者登记过的设备上；你需要用自己的证书重新签名，或者自己从源码编译。
